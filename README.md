# Audubon Facial Plastics Theme

قالب وردپرسی حرفه‌ای و فارسی برای کلینیک جراحی زیبایی، بر اساس طراحی مدرن و مینیمال سایت Audubon Facial Plastics.

## ویژگی‌ها
- راست‌چین و فارسی کامل
- سازگار با وردپرس و المنتور
- منوهای چندسطحی و هدر حرفه‌ای
- صفحات اصلی و داخلی آماده
- انیمیشن‌های سبک و حرفه‌ای
- بخش‌های خدمات، تیم متخصص، گالری، نظرات، بلاگ و تماس
- نسخه ریسپانسیو برای موبایل و دسکتاپ

## نصب
1. فایل پوشه `wp-content/themes/audubon-facial-plastics` را به پوشه `wp-content/themes` وردپرس منتقل کنید.
2. در پیشخوان وردپرس، از بخش ظاهرشدگی -> پوسته‌ها، پوسته را فعال کنید.
3. برای بهترین نتیجه، افزونه Elementor را نصب و فعال کنید.
4. منو و صفحات اصلی را از تنظیمات وردپرس مدیریت کنید.

## ساختار اصلی
- `front-page.php` : صفحه اصلی
- `header.php` / `footer.php` : ساختار هدر و فوتر
- `page.php` : صفحات استاندارد
- `single.php` / `archive.php` : پست‌ها و آرشیو
- `assets/css/theme.css` : استایل‌های اصلی
- `assets/js/theme.js` : انیمیشن‌ها و رفتارهای پوسته

## نکته
این قالب پایه‌ای قوی و کاملاً فارسی است و به‌راحتی می‌تواند توسط Elementor شخصی‌سازی و توسعه پیدا کند.
