# تصاویر نمونه محلی قالب

تمام تصاویر نمونه این نسخه به‌صورت فایل SVG داخل قالب قرار گرفته‌اند و هیچ‌کدام از URL خارجی استفاده نمی‌کنند.

- `hero-clinic.svg`: تصویر اصلی صفحه خانه
- `doctor-sara.svg`, `doctor-amir.svg`: کارت تیم پزشکی
- `before-after-face.svg`, `before-after-profile.svg`: گالری قبل و بعد
- `consultation.svg`, `patient-care.svg`: بخش‌های معرفی و تجربه بیمار

این تصاویر، تصاویر گرافیکی نمونه و قابل جایگزینی هستند؛ برای استفاده تجاری، تصاویر واقعی و دارای مجوز بیماران/پزشکان خودتان را جایگزین کنید.
